# Frequency_Twilight: 
Программа выводит 20 наиболее частотных слов (кроме стоп-слов) из романа Стефани Майер "Сумерки". В отдельном файле представлен анализ влияния этих лексем на смысл произведения. Слова распределены на лексико-семантические и тематические группы для более качественного анализа. Распределение строк кода:
Наталия Кашкарова: 12-15, 30-34, 36-53.
Кулагина Софья: 9-10, 17-28 + анализ влияния частотных слов на смысл произведения.
